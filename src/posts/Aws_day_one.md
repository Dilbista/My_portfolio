# Day 1: Introduction to Cloud Computing and AWS ☁️

Today was my **first day learning Cloud Computing and AWS**.

I started with the basic concepts because I want to understand what cloud computing actually means before working with different AWS services.

---

## ☁️ What is Cloud Computing?

The first thing I learned today was the definition of **Cloud Computing**.

In simple words, cloud computing means using computing resources through the internet instead of using only our own physical computer or server.

These resources can include:

- Servers
- Storage
- Databases
- Networking
- Computing power
- Applications

For example, instead of purchasing a physical server and maintaining it ourselves, we can use a server provided by a cloud service provider.

---

## 🌐 Cloud Computing Platforms

I also learned that there are different cloud computing platforms available.

Some popular cloud platforms are:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

These platforms provide different services that can be used to build, deploy, and manage applications.

---

## 🟠 Introduction to AWS

After understanding the basic concept of cloud computing, I started learning about **AWS**.

AWS stands for **Amazon Web Services**.

AWS is a cloud computing platform provided by Amazon.

It provides many different services for computing, storage, databases, networking, security, application development, and deployment.

Some AWS services I came across today include:

- Amazon EC2
- Amazon S3
- Amazon RDS
- IAM
- VPC
- AWS Lambda
- CloudFront
- AWS Amplify

Today I only focused on understanding what AWS is and what types of services it provides.

## 💳 AWS Free Tier

Another basic topic I learned about was the **AWS Free Tier**.

AWS offers free usage for certain services within specific limits.

However, not every AWS service or usage level is necessarily free.

So, while learning AWS, it is important to understand:

- Free usage limits
- Service pricing
- Resource usage
- Billing
- Removing resources that are no longer required

This is important because cloud services can generate charges if resources are used beyond applicable free limits.
