# Day 4: AWS EC2 & RDS ☁️🗄️

Today I continued my **AWS learning journey** by practicing **Amazon EC2** and **Amazon RDS**.

I focused on understanding how EC2 is used to run applications and how RDS is used to manage databases.

---

## ☁️ Amazon EC2

**EC2 (Elastic Compute Cloud)** provides virtual servers in AWS.

Today I learned about:

* 🖥️ EC2 Instances
* 💿 AMI
* ⚙️ Instance Types
* 💾 EBS Storage
* 🔐 Security Groups
* 🌐 Public IP and server access

In simple words:

> **EC2 is a virtual server used to run applications and websites.**

---

## 🗄️ Amazon RDS

**RDS (Relational Database Service)** is a managed database service from AWS.

I learned about:

* 🗄️ Database Instances
* 🐬 MySQL
* 💾 Database Storage
* 🔐 Database Security
* 💿 Backups
* 🔗 Connecting applications to databases

In simple words:

> **RDS makes it easier to create and manage relational databases in AWS.**

---

## 🔗 EC2 + RDS

I learned how EC2 and RDS can work together:

```text
🌐 User
   ↓
☁️ EC2
   ↓
💻 Application
   ↓
🗄️ RDS
   ↓
🐬 MySQL Database
```

**EC2** runs the application, while **RDS** stores and manages the application's database.

---

## 🧠 What I Learned

Today I understood the basic relationship between **compute and database services** in AWS.

> **EC2 → Run the Application**
> **RDS → Manage the Database**

This practical learning helped me understand how real-world applications can be deployed using AWS.
