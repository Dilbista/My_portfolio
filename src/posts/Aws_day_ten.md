## 📊 What is Amazon CloudWatch?

**Amazon CloudWatch** is a monitoring and observability service that helps me collect and monitor metrics, logs, and other information from AWS resources and applications.

The basic idea is:

```text
AWS Resources
     ↓
CloudWatch
     ↓
Metrics + Logs
     ↓
Monitor + Analyze
     ↓
Alarms / Actions
```

One important feature I learned about is **CloudWatch Alarms**.

An alarm watches a metric and changes state when a configured threshold is met.

For example:

```text

CloudWatch Alarm
      ↓
```

# 📁 Log Groups

CloudWatch Logs organizes logs into **log groups** and **log streams**.

A simple structure is:

```text
Log Group
   ├── Log Stream 1
   ├── Log Stream 2
   └── Log Stream 3
```

A log group can contain multiple log streams.

CloudWatch alarms can work with **Amazon SNS** for notifications.

# 🧠 Important CloudWatch Concepts

### Metric

A numerical measurement collected for monitoring.

### Alarm

A monitoring rule that changes state when a metric meets a configured condition.

### Log

Recorded information from applications, systems, or services.

### Log Group

A collection of related log streams.

### Log Stream

A sequence of log events from a particular source.

### Dashboard

A visual place where monitoring information can be organized and viewed.

---

# 🆚 CloudWatch Metrics vs Logs

| Metrics                      | Logs                             |
| ---------------------------- | -------------------------------- |
| Numerical measurements       | Recorded events and messages     |
| Useful for monitoring trends | Useful for investigating details |
| Example: CPU utilization     | Example: application error       |
| Usually shown as graphs      | Usually viewed as log events     |

Both metrics and logs are useful for monitoring applications and infrastructure.
