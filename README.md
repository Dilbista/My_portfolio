# Dil Bista Portfolio

A React and Vite portfolio website that runs entirely in the browser. Hero
content, skills, projects, and images are stored in the source code, so the
site does not require Laravel, a database, or any API server.

## Run locally

```bash
npm install
npm run dev
```

## Build for static hosting

```bash
npm run build
```

Upload the generated `dist` folder to any static host such as GitHub Pages,
Netlify, or Vercel. The contact form opens the visitor's default email app
using a `mailto:` link; it does not send data to a backend.
